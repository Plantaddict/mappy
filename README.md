# Mappy

Turn any place on Earth into a print-ready map poster, built on OpenStreetMap data.

**Status:** product definition. No code yet.

- [Product Requirements Document](docs/PRD.md): consumer poster site; problem, users, scope, requirements, metrics, OSM compliance, and roadmap.
- [Seller platform exploration](docs/seller-platform-exploration.md): is selling the engine to Etsy / print-on-demand sellers a better business? Market, competitors, product shape, pricing, risks, and a 4-week validation plan.

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
